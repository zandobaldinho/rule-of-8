Where each rule shows up
  1. Consistency: one row component, one verb per action.
  2. Universal usability: 48 px targets on touch; / search.
  3. Feedback: the row turns green in place and the queue count drops.
  4. Closure: the toast says what changed and what's next.
  5. Error prevention: no destructive button on the row.
  6. Easy reversal: Undo in the toast and on the row itself.
  7. User in control: the resolved row stays until you switch queues.
  8. Less memory load: each row says what is missing.
